# Default settings

Put a `settings.json` here, made with **Edit → Export** on the New Tab page.
When the extension starts with empty storage (a fresh install, or this folder
loaded under a new extension ID), it loads your shortcuts, wallpaper and
settings from it.

`settings.json` is in `.gitignore`, so it stays on your computer and
`git pull` leaves it alone. This repository is public: only commit it (with
`git add -f defaults/settings.json`) if you're happy for your shortcuts and
wallpaper to be public.
